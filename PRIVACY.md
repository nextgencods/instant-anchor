# Privacy Policy

Instant Anchor does not operate a server and does not maintain user accounts.

## Data collection

No analytics, telemetry, advertising identifiers, or behavioral tracking are included.

## Data storage

Anchors, page metadata, and notes are stored locally in the browser through `chrome.storage.local`.

## Data transmission

Instant Anchor does not intentionally transmit notebook data to the developer or to third-party services.

## Backup and export

Markdown and JSON exports are created locally in the browser. Import reads only a backup file explicitly selected by the user.

## Uninstalling

Removing the extension may remove its browser-managed local storage. Export a JSON backup before uninstalling if you want to preserve your notebook.
