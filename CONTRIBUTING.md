# Contributing

Thanks for your interest in improving Instant Anchor.

## Before opening a pull request

1. Keep the extension local-first and privacy-minimized.
2. Do not add analytics, telemetry, remote code, or broad host permissions without explicit discussion.
3. Run `./audit.sh`.
4. Run `node --check background.js` and `node --check content.js`.
5. Test normal page scrolling and at least one nested-scroll layout.

## Pull requests

Keep changes focused. Explain the user-visible behavior, privacy impact, and test coverage in the PR description.
